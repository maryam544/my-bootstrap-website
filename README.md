# My Bootstrap Website

A responsive one-page website built with Bootstrap 5.

## Files
- `index.html` — page structure, Bootstrap components, and small form demo script
- `style.css` — custom styling

## Run
Open `index.html` in a browser. An internet connection is needed for Bootstrap CDN, Bootstrap Icons, and remote images.

The contact form is a front-end demo only; it does not send messages to a server.
